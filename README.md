# Quick AI Tools — Fixed GitHub Pages Version

Upload ALL THREE files to the SAME GitHub repository folder:
- index.html
- style.css
- app.js

IMPORTANT: `app.js` is required. If you upload only index.html and style.css, the tool buttons will not work.

GitHub Pages:
Settings → Pages → Deploy from branch → main → /(root) → Save.

The browser tools work without an API key. PDF extraction needs internet access because PDF.js is loaded from cdnjs.
Real cloud AI (ChatGPT/Claude/Gemini) is not included; that requires a secure backend/API key.
